Login com Google

Para liberar o botão “Entrar com Google”, crie um ID de cliente OAuth no Google Cloud Console (tipo “Aplicativo da Web”), libere o endereço onde o sistema está publicado em Origens JavaScript autorizadas e cole o ID abaixo.

O login com Google só funciona com o sistema publicado em um endereço http:// ou https://. Abrindo o arquivo direto do computador (endereço file://) o Google recusa a conexão — nesse caso use o login por e-mail e senha.
